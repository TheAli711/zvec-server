# Tickets

One file per unit of work: `ZS-NNN-short-slug.md`, numbered sequentially and never
reused. Every ticket belongs to a spec in [`../specs/`](../specs). Start from
[`../specs/_templates/ticket.md`](../specs/_templates/ticket.md).

The board of all tickets is [`../TRACKER.md`](../TRACKER.md), generated by
`python scripts/tracker.py`. The full workflow is in
[`../specs/README.md`](../specs/README.md).
